citebook-ai ↗

RAG service with checked citations · personal project

Developing a RAG service with Spring Boot 4 and Spring AI that indexes a course's PDFs in pgvector, with embeddings generated locally in Ollama, and answers questions with citations (file and page) checked against the retrieved excerpts.

More details
  • Exposing the same engine through a REST API, used by an Angular UI that shows each answer with linked sources, and an MCP server with read-only tools for external assistants, as two inbound adapters in a Hexagonal Architecture.
  • Evaluating retrieval with 25 questions in an automated test on GitHub Actions (hit rate@5 of 0.88), testing 9 prompt-injection attacks against the answer path and tracking rejected citations in Prometheus and Grafana.
